JGI Personal AI Assistant
A responsive, customizable AI chatbot designed for college students. This web application provides quick answers to queries about notes, timetables, and exams using mock data. It is built with vanilla HTML, CSS, and JavaScript, with no external frameworks.

Features
Interactive Chat Interface: A clean and modern chat UI for interacting with the AI bot.

Dynamic Vortex Background: A captivating, animated vortex background created with HTML5 Canvas.

Full Customization: A settings panel allows users to personalize the experience in real-time:

UI Color: Change the color of chat bubbles and buttons.

Vortex Colors: Customize both the particle and background colors of the vortex animation.

Font Size: Adjust the chat font size for readability.

Toggle Animation: Turn the background animation on or off.

Voice Welcome: Greets the user by name with a voice message upon opening the app.

Persistent Settings: All user customizations are saved in the browser's local storage.

Framework-Free: Built entirely with standard HTML, CSS, and JavaScript for maximum compatibility and no build steps.

How to Use
Download the files: Clone or download the index.html file from this repository.

Open in a browser: Simply open the index.html file in any modern web browser (like Chrome, Firefox, or Edge).

Interact:

Type questions into the search bar (e.g., "What is my schedule tomorrow?").

Click the settings icon in the top-right corner to customize the look and feel.

File Structure
index.html: The single, self-contained file that includes all the HTML structure, CSS styling, and JavaScript logic for the application.

This project was created to demonstrate a fully functional, interactive, and customizable web application without relying on external frameworks.
